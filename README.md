# SOC Home Lab (ELK + Suricata + Threat Intelligence)

## 📌 Overview
This project demonstrates a Security Operations Center (SOC) lab using ELK Stack and Suricata IDS for real-time threat detection.

## 🛠️ Tools Used
- Elasticsearch
- Logstash
- Kibana
- Filebeat
- Suricata IDS
- VirusTotal API
- AlienVault OTX

## ⚙️ Setup
- Installed and configured ELK Stack
- Configured Suricata IDS
- Integrated Filebeat for log forwarding
- Visualized logs in Kibana

## 🚨 Attack Simulation
- Nmap scans
- Curl HTTP requests

## 📊 Features
- Real-time alert detection
- Threat intelligence enrichment
- Dashboard visualization
